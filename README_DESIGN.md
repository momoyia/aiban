爱伴 (AiBan) - 摄影分享App 产品设计文档

1. 产品愿景与用户体验分析 (UX Analysis)

1.1 核心理念

“爱伴”不仅仅是图片流，它是光影与情感的连接。我们主打“陪伴式摄影”，鼓励用户记录生活中的美好瞬间并寻找共鸣。

1.2 目标用户

审美追求者：喜欢高品质视觉内容，对排版和色彩敏感。

情感表达者：习惯通过图片而非长文表达情绪。

摄影爱好者：需要一个纯粹、无干扰的展示平台。

1.3 独特的交互路径 (Unique Operation Paths)

为了区别于普通App，我们引入以下独特设计：

“呼吸感”浏览体验：Feed流中的图片不采用传统的全屏分割，而是采用悬浮卡片式，卡片之间有微妙的视差滚动效果，背景随着图片主色调进行极淡的模糊渐变（原型中通过白色背景+光晕模拟）。

“长按沉浸”模式：在首页或探索页，长按任意图片，界面UI（导航栏、文字）全部隐去，仅保留图片本身，提供极致的纯净观看体验。

情感化微交互：点赞不再是简单的变红，而是绽放一个带有渐变色的光圈（紫色至玫红）。

2. 界面规划与功能架构 (Information Architecture)

2.1 首页 (Home) - 沉浸发现

顶部导航：悬浮透明设计，包含 [发现]、[关注]、[榜单]。

Banner区：并非传统轮播，而是“画廊式”横向滑动，带有聚焦放大效果。

Feed流：

核心内容：大尺寸摄影图（4:5或3:4比例）。

交互区：悬浮于图片下方的毛玻璃操作条（点赞、评论、分享）。

关注逻辑：头像旁边的优雅“+”号，点击后渐变为“已关注”并消失。

2.2 探索 (Explore) - 灵感瀑布

专题模块：[精选作品] 与 [热门分类] 的胶囊式切换。

视觉瀑布流：

双列不等高布局（Pinterest风格）。

分类蒙版：图片固定比例，上方覆盖半透明渐变蒙层，显示分类名称（如“人像”、“胶片”、“极简”）。

2.3 消息 (Messages) - 极简连接

通知聚合：顶部的互动通知（点赞/收藏）。

私信列表：极简风格，仅展示头像、昵称和最后一条信息，右滑可快速操作。

2.4 我的 (Profile) - 个人画廊

头部设计：大留白，左侧大头像，右侧精简数据（关注/粉丝/获赞）。

设置入口：右上角极简齿轮图标。

内容选项卡：[作品]、[收藏]、[喜欢] 的滑动切换。

3. UI 设计规范 (UI Design System)

3.1 色彩体系 (Color System)

背景色：#FFFFFF (纯白，确保图片是主角)。

品牌主色 (Brand Gradient)：

Start: #8E2DE2 (深紫，代表神秘与深度)。

End: #F000FF (玫红，代表热情与活力)。

应用场景：按钮背景、图标激活态、关键文字高亮、Loading动画。

辅助色：

文本黑：#1A1A1A (主要标题)。

文本灰：#8E8E93 (次要信息)。

分割线：#F5F5F7 (极淡，几乎不可见)。

3.2 字体与排版 (Typography)

字体：iOS系统字体 (SF Pro Display / PingFang SC)。

风格：标题使用 Semibold，正文使用 Regular。

留白：遵循 8pt 栅格系统，模块间距加大（24px+），营造“空气感”。

3.3 图标与圆角 (Icons & Radius)

圆角：

卡片：20px (大圆角，亲和力)。

按钮：999px (全圆角)。

图标风格：Outline（线性）风格，选中时变为 Solid（填充）并应用品牌渐变色。
